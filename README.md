# Restaurant Management System – SQL Project

## About the Project

This project is based on a Restaurant Management System created using MySQL. The main goal is to manage restaurant-related data and understand business performance through SQL queries.

The project includes customer details, employee information, menu items, orders, and payment records. I used SQL queries to explore the data and find useful insights that can help a restaurant understand its sales, popular menu items, employee performance, and customer spending.

## Project Objectives

- Manage restaurant data using a structured relational database.
- Analyze sales and revenue using SQL queries.
- Identify the most frequently ordered menu items.
- Understand employee performance based on order revenue.
- Analyze customer spending and payment methods.
- Track order statuses, including completed, pending, and cancelled orders.

## Tools & Technologies

- **Database:** MySQL
- **Language:** SQL
- **Concepts:** Joins, Aggregate Functions, GROUP BY, ORDER BY, Subqueries, CASE Statements, Window Functions, and Filtering.

## Key Analysis & Business Insights

### 1. Menu Item Analysis
- Identified the top 10 most frequently ordered menu items.
- Sorted menu items by price to find the most expensive dishes.
- Categorized sales amounts into high, medium, and low groups.

### 2. Sales & Revenue Analysis
- Calculated total sales using payment records.
- Analyzed monthly revenue to understand sales trends.
- Compared revenue generated through different payment methods.

### 3. Customer Analysis
- Identified customers with the highest spending.
- Ranked customers based on their total spending.
- Retrieved customer records, including customers who had not placed orders.

### 4. Employee Performance
- Analyzed revenue generated by employees.
- Identified employees who handled the highest number of orders.
- Used employee information to explore performance across different roles.

### 5. Order & Payment Analysis
- Counted completed, pending, and cancelled orders.
- Retrieved detailed order information by joining multiple tables.
- Filtered orders by date and analyzed payment transactions.
